# Security Policy

## Supported versions

The latest minor release receives security fixes.

## Reporting a vulnerability

Use GitHub's private security-advisory feature for this repository. Do not open a public issue containing secrets, personal housing records or exploit details.

## Security and privacy scope

This project processes local CSV and JSON inputs. It does not scrape listings, transmit data, authenticate to third-party services or place housing applications. The public example is synthetic.

Users remain responsible for protecting any private input files. Keep them outside the repository, use restrictive file permissions, and never commit them to version control.
