# Development Disclosure

This repository was developed with AI-assisted coding and review tools under human direction.

The public release is not a dump of private conversation or generated research. It is a clean-room implementation with:

- an explicit product boundary;
- independently inspectable source code;
- synthetic committed data;
- deterministic outputs;
- unit and integration tests;
- privacy and secret scanning;
- a reproducibility manifest;
- manual visual review of the HTML report.

AI assistance does not establish correctness. The code, tests, formulas, limitations and publication boundary should be evaluated on their own merits.
