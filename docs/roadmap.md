# Roadmap

## v0.1 — complete

- dependency-free CLI;
- validation and explicit as-of date;
- hard constraints and weighted scoring;
- Pareto, sensitivity and budget analysis;
- CSV, JSON, HTML and SQLite outputs;
- deterministic synthetic example;
- tests, privacy scanner and CI.

## v0.2 — evidence quality

- criterion-level evidence records;
- confidence and evidence-source fields;
- configurable qualitative scoring rubrics;
- comparison of independent scorers;
- uncertainty bands rather than point estimates only.

## v0.3 — adapters

- optional geocoding and transit adapter interfaces;
- import templates for common listing exports;
- source-license and retrieval-date registry;
- pluggable exchange-rate provider with cached provenance.

## v0.4 — user experience

- interactive local web interface;
- editable weights and constraints;
- visual sensitivity tornado chart;
- side-by-side lease-cost scenarios;
- export adapter for accessible spreadsheets.

## Non-goals

- automated applications;
- scraping behind authentication;
- predictive crime or applicant-approval scoring;
- cloud collection of personal housing data.
