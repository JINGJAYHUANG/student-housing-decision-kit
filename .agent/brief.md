# Brief

## Product

`student-housing-decision-kit` is a dependency-free Python toolkit that converts a listing CSV and preference JSON into an explainable, auditable housing comparison.

## Public value

The project demonstrates decision modeling, data validation, temporal provenance, privacy-by-design, sensitivity analysis, relational exports and reproducible reporting.

## User-facing promise

A user can see what passed, what failed, why it failed, how each score was built and whether the ranking survives reasonable changes in assumptions.

## Public boundary

Only synthetic example data belongs in this repository. Private runs occur outside the repository and are never committed.
